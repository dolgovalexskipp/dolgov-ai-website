Workshop · Бизнес-клуб Команда

Проектирование AI-сотрудников

13-я Выездная Школа Бизнес-клуба «Команда». Красная Поляна, июнь 2026. Двухдневный hands-on workshop для CEO и собственников. До 15 участников.
Спикер: Александр Долгов — основатель и управляющий директор VEYRA, основатель Долгов AI и партнёры.

Это рабочий документ для согласования с организаторами Школы. Не публичная страница для участников. Финальная версия материалов для участников будет подготовлена отдельно после согласования программы.

Цель школы

За два дня каждый участник проходит путь от карты собственного бизнеса до рабочего прототипа AI-сотрудника, встроенного в конкретный процесс. Не знакомство с технологией — собственный артефакт на выходе.

На выходе у участника:

  • Карта бизнеса с найденным узким местом — отвечает на вопрос «где первый AI-сотрудник даст реальный сдвиг»
  • Рабочий прототип AI-сотрудника под этот процесс, проверенный на собственных данных
  • Roadmap следующих 2–3 сотрудников — куда расширять контур после школы
  • Шаблоны и стартовый набор — чтобы продолжить самостоятельно

Подход

Два принципа, которые я проношу через школу. Это и есть содержательная разница со стандартным «курсом по AI»:

AI ставится на узкое место, не на удобное
Опираемся на Theory of Constraints (Голдратт). Сначала находим, где у бизнеса самое медленное звено. Туда ставим первого AI-сотрудника. «Автоматизировать всё» — антипаттерн, расходующий ресурс впустую.
Инженерия, не vibe coding
Демо собрать легко, рабочую систему — нет. Учим проектировать контур: роль, инструменты, память, правила, интеграции, безопасность. То, что переживёт первую неделю эксплуатации.

Образовательная логика

Программа построена как сквозной образовательный путь, в котором каждая стадия закрывает свою функцию:

  1. Погружение — 0 день. Рамка, контекст, что значит работать с AI инженерно.
  2. Примеры — утро дня 1. Живые демо моих рабочих AI-сотрудников.
  3. Правила — день 1. Как искать узкое место, как устроен AI-сотрудник, какие принципы инженерии.
  4. Самостоятельная деятельность — день 1 вечер и день 2 первая половина. Каждый собирает прототип.
  5. Корректировки — параллельно сборке. Я обхожу, помогаю, перепроверяем гипотезы.
  6. Результат — финал дня 2. Демо-сессия, обратная связь, roadmap.

Результат: демо-сессия
Каждый по 4–5 минут: вот что я нашёл как узкое место, вот кого собрал, вот что он умеет. Группа даёт обратную связь. Финал — roadmap следующих 2–3 сотрудников и как продолжить после школы.

Что забирает участник

  • Рабочий прототип AI-сотрудника, проверенный на собственных данных
  • Карта бизнеса с найденным узким местом и обоснованием
  • Шаблон TZ для следующих AI-сотрудников
  • Понимание principles agentic engineering — чем рабочая система отличается от демо
  • Roadmap следующих 2–3 сотрудников под свой бизнес
  • Стартовый набор из 5 публичных скиллов как референс структуры (см. ниже)
  • Возможность продолжить со мной в формате проектного консалтинга, если нужно довести до production

Что нужно от участников до приезда

Pre-req checklist рассылается организаторами участникам за неделю до школы. Без выполнения первый день идёт вхолостую — это критично.

Hardware

  • Ноутбук с 16 GB RAM минимум, 32 GB желательно
  • Стабильный интернет, мобильный интернет как backup
  • Зарядка, переходники по необходимости

Software

  • Cursor или VS Code (на выбор, инструкция в письме)
  • Claude Code CLI (установка по инструкции)
  • Claude Desktop
  • Telegram Desktop
  • Опционально: ChatGPT Desktop

Подписки

  • Claude Pro или Claude Max — обязательно
  • ChatGPT Plus — желательно
  • API key Anthropic — желательно для интеграций

Аккаунты

  • GitHub (бесплатный)
  • Telegram (если планируется собирать Telegram-бота)
  • Доступ к собственному рабочему стеку: CRM / таблицы / почта / то, с чем хочется интегрировать агента

Контент к приезду — обязательно

  • Карта бизнеса на одну страницу: ключевые процессы, основные роли, главная метрика, которую хочется сдвинуть. Шаблон будет в письме.
  • Список повторяющихся задач, которые делаются руками каждую неделю — материал для будущих агентов.

Время и настрой

  • 0 день вечер: 1.5–2 часа без отвлечений
  • Дни 1 и 2: полные дни 9:00–16:00 без оперативки
  • Готовность работать руками, а не слушать

Стартовый набор скиллов для участников

Публикую в виде GitHub-репозитория к началу школы. Универсальные, не завязанные на мою инфру, — чтобы каждый мог запустить сразу и увидеть структуру skill-файла.

meeting-recap
Встреча → структурированный recap с ключевыми решениями, задачами, follow-up.
content-draft
Идея + материалы → черновик поста / статьи в собственном голосе.
weekly-review
Материалы недели → дайджест / повестка планёрки.
process-transcript
Любой транскрипт → автодетект типа → нужный артефакт под него.
task-router
Входящая задача (письмо / сообщение) → классификация и маршрутизация.
