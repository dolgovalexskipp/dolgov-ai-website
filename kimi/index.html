KDA хранит состояние истории

Что хранится

Матрица состояния на голову. В K3.1: 96 голов с размерностью 128.

При decode не нужно перечитывать всю историю в каждом KDA-слое.

TP, EP и связи между GPU

TP: матрицы

Части одной операции считают разные GPU. Нужны частые быстрые обмены.

Авторегрессионная модель строит ответ последовательно. Она получает доступный префикс, вычисляет logits, то есть ненормированные оценки кандидатов, и преобразует их в распределение вероятностей. Greedy выбирает максимальную оценку, sampling делает выбор из распределения, top-p ограничивает набор кандидатов накопленной вероятностью. Kimi Delta Attention поддерживает для каждой головы матричное состояние. Оно служит компактным носителем накопленных ассоциаций ключей и значений. Полный пример:

import json
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="unused-local", timeout=300.0)
tools = [{"type": "function", "function": {
    "name": "get_stock", "description": "Вернуть остаток товара по SKU.",
    "parameters": {"type": "object", "properties": {"sku": {"type": "string"}},
                   "required": ["sku"], "additionalProperties": False}}}]
messages = [{"role": "user", "content": "Сколько SKU A-100 на складе? Вызови get_stock."}]
for step in range(8):
    response = client.chat.completions.create(
        model="moonshotai/Kimi-K3.1-Pro", messages=messages, tools=tools,
        tool_choice="auto", reasoning_effort="low", max_tokens=4096)
    choice = response.choices[0]
    if choice.finish_reason == "length":
        raise RuntimeError("Output limit reached")
    assistant = choice.message.model_dump(exclude_none=True)
    messages.append(assistant)
    calls = assistant.get("tool_calls") or []
    if not calls:
        print(assistant.get("content") or "")
        break
    for call in calls:
        fn = call["function"]
        args = json.loads(fn["arguments"])
        if (fn["name"] != "get_stock" or not isinstance(args, dict)
            or set(args) != {"sku"} or not isinstance(args["sku"], str)):
            raise ValueError("Tool or arguments rejected")
        result = {"sku": args["sku"], "quantity": 12, "source": "demo"}
        messages.append({"role": "tool", "tool_call_id": call["id"],
                         "content": json.dumps(result, ensure_ascii=False)})
else:
    raise RuntimeError("Tool step limit reached")
