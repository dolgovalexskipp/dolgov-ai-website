# Бриф на иллюстрации — Долгов, Эй Ай и партнеры

> Для команды. Стиль: мягкие формы, warm paper палитра, без AI-клише (роботы, мозги, чипы).
> Референс дизайн-системы: style-guide.css

---

## Секции, которые "дышат" и просят визуала

### 1. Hero — "AI уже есть у всех. Система — у единиц"
**Сейчас:** только текст, много воздуха справа.
**Метафора: Дирижёр и оркестр**
Один человек управляет сложной системой, где каждый элемент играет свою партию. Не делает всё сам — оркестрирует.
- Вариант: абстрактная фигура дирижёра с линиями-связями к элементам (документы, данные, процессы)
- Вариант: пульт управления с мягкими формами — не dashboard, а скорее mixing console

### 2. Два режима — "Ускоритель vs Оркестратор"
**Сейчас:** два текстовых столбца.
**Метафора: Велосипед vs Экзоскелет**
Слева: человек крутит педали быстрее (тот же процесс, ускоренный). Справа: человек в экзоскелете — принципиально другой масштаб возможностей.
- Вариант: два контрастных силуэта — один бежит быстрее, другой летит
- Вариант: конвейер (слева линейный, справа — разветвлённая система с узлами)

### 3. Процесс — "Одна сессия = один час"
**Сейчас:** 3 шага текстом + mock артефакта.
**Метафора: Кристаллизация**
Хаотичные элементы (задачи, инструменты, контекст) → через сессию → структурированный кристалл (система).
- Вариант: от тумана/облака к чёткой геометрической форме
- Вариант: от разбросанных пазлов к собранной картине

### 4. Кейс VEYRA — "AI-first компания изнутри"
**Сейчас:** цифры + списки, визуально плоско.
**Метафора: Second Brain / Нервная система**
Центральный узел (founder) с отходящими нитями к разным функциям (продажи, разработка, контент, юр.документы). Живая, пульсирующая система.
- Вариант: схема нервной системы — центр + ответвления с подсвеченными узлами
- Вариант: карта метро / circuit board с тёплой палитрой

### 5. Обучение — "Как изучение языка, но с дофамином"
**Сейчас:** текст + 3 карточки.
**Метафора: Язык / Погружение**
Не учебник с правилами, а погружение в среду. Как переезд в другую страну — через практику, не через теорию.
- Вариант: человек в "среде" из AI-элементов (файлы, потоки, связи) — комфортно, не страшно
- Вариант: спираль обучения — каждый виток добавляет слой (инструменты → сценарии → система → автоматизации)

### 6. CTA — "Начать можно с одной задачи"
**Сейчас:** тёмный блок с текстом.
**Метафора: Первый шаг / Дверь**
Простой, нестрашный вход в большое пространство.
- Вариант: открытая дверь с тёплым светом — приглашение
- Вариант: одна точка, от которой расходятся возможности (mindmap growth)

## Технические требования

- Формат: SVG (для web) + PNG @2x (для fallback)
- Палитра: --paper (#f6f0e6), --green-900 (#173a28), --green-700 (#3a754d), --muted (#67635d)
- Стиль: мягкие формы, без острых углов, тёплый и уверенный
- НЕ использовать: роботов, мозги, чипы, матрицу, neon glow
- Размеры: адаптивные, основной контейнер max-width 1320px
