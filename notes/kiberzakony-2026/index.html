Как собиралась таблица

Ручной веб-поиск и сверка реквизитов по pravo.gov.ru, «Гарант» и «КонсультантПлюс», плюс контрольный проход через Yandex Cloud Search API с автосборкой черновика в GigaChat‑2‑Max — с обязательной ручной проверкой каждой строки: автосборка GigaChat однажды подставила в черновик указ о кадровых назначениях, никак не связанный с темой (совпал по формальным ключевым словам запроса) — такие строки из финальной таблицы удалены вручную.

Это компиляция из открытых источников, а не выгрузка из базы НПА — для юридически значимого использования (договоры, комплаенс) реквизиты стоит сверить напрямую на pravo.gov.ru.
