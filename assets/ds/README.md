# Дизайн-система Dolgov AI · v0.3

Одна система для сайта dolgovalex.com и материалов Dolgov AI. Витрина: `/ds/` (закрыта от индексации).

## Основа

VEYRA Design System — ДС кабинета голосовых агентов (Claude Design, проект `06bbdfdb`) в том виде, как она работает в INWRAP ERP (`~/inwrap-mvp`, `frontend/src/theme.css`). Меню сайта сверху, страница лежит на сером; окно приложения (`.window`) и карточки (`.card`) — элементы внутри страниц (решение Саши 26.10.2026). Окном показываем контур так, как его увидит компания.

Что взято без изменений: фон и градиент, карточки, тени, радиусы, чёрные кнопки-пилюли, подсказки клавиш, Geist и Geist Mono, иконки lucide, правило «цвет — сигнал, не украшение», одна светлая тема.

Что своё:

| Что | VEYRA | Dolgov AI | Почему |
|---|---|---|---|
| Акцент (теги, выделение, ссылки, моно-подписи) | индиго #4f46e5 | зелёный #177245 | решение Саши 26.10.2026 |
| Знак | VEYRA LAB / INWRAP | DOLGOV AI | тот же принцип: слово жирным, приписка цветом |
| Текст | 14 | 16 | сайт читают, а не работают в нём |
| Заголовок первого экрана | нет | `.display` 34–52, 700 | у кабинета нет первого экрана |
| Фирменный элемент | граф маршрута | схема AI-контура узлами | продукт Dolgov AI — контур |
| Статусы | success #16a34a (3,3:1) | зелёный акцента, warn #8a5a00 | контраст 4,5:1 для текста |

## Файлы

- `tokens.css` — шрифты, поверхности, текст, акцент, статусы, тени, радиусы, шкала, сетка.
- `components.css` — база, шапка сайта, страница, окно приложения, кнопки, теги, карточки, таблицы, схема, цифры, тарифы, вопросы, подвал.
- `ds.js` — меню сайта на ≤900 px: кнопка раскрывает панель под шапкой, закрывают Esc и переход по пункту.
- `icons.svg` — спрайт lucide 0.454.0 (ISC, `LICENSE-lucide.txt`): `<svg class="i"><use href="/assets/ds/icons.svg#graduation-cap"/></svg>`.
- `fonts/` — Geist (400–700) и Geist Mono (400–600), подмножества latin, latin-ext, cyrillic, OFL.

Подключение:

```html
<link rel="preload" href="/assets/ds/fonts/geist-cyrillic.woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/assets/ds/tokens.css">
<link rel="stylesheet" href="/assets/ds/components.css">
<script src="/assets/ds/ds.js" defer></script>
```

## Каркас страницы

```
header.site-head > .wrap.in   .brand, .nav (слова; текущий — серая плашка), .head-cta (.cmd, .btn-primary, .menu-btn)
                 > .wrap.head-panel   меню на ≤900 px: пункты с иконками и кнопка
main
  .wrap.page-head   .title-row (.h1, .tag, .meta), .lead, .btns, .tabs
  .wrap             первый экран, секции .sec с .sec-head
  .wrap.page-body   .with-aside > содержимое + aside.aside (по желанию)
```

Окно приложения внутри страницы:

```
.window
  .window-bar    .dots, .wtabs (span.on — открытая вкладка, span.dirty — с правками), .wsearch
  .window-body   .window-nav (.wbrand, span.on, span.sub) + .window-main (.window-head, таблица, .window-foot)
```

На ≤1080 прячется поле `.cmd`, на ≤900 меню сворачивается в кнопку, на ≤760 у окна прячется левое меню.

## Цвет

| Токен | Значение | Где |
|---|---|---|
| `--page-grad` | #eff4f7 → #f2f2f3 → #f5f5f4 | фон страницы |
| `--card` | #ffffff | окно, карточки, шапка сайта |
| `--card-2` | #f7f7f8 | вложенные плашки, схема контура |
| `--border` / `--hair` | #e5e5e5 / rgba(23,23,23,.06) | границы / разделители |
| `--primary` | #171717 | основная кнопка, заголовки |
| `--fg` / `--muted` | #0a0a0a / #666666 | текст / вторичный (5,7:1) |
| `--accent` | #177245 | моно-подписи, ссылки, выделенная строка, «?» (6:1) |
| `--accent-tint` | зелёный 8% | фон выделенной строки и тега |
| `--warn` / `--danger` | #8a5a00 / #d92d2d | «черновик», «ждёт согласия» / ошибки |

Тени только чёрные и мягкие: `--sh-xs` поля и контурные кнопки, `--sh-sm` карточки, `--sh-md` меню, `--sh-panel` + `--sh-lg` окно приложения.

## Текст

- Geist везде, Geist Mono — для надписей разделов (`.mlabel`, «02 · ЦВЕТ»), клавиш (`.kbd`), кодов и времени в таблицах.
- `.display` 34–52/700, `.h1` 28–36/700, `.h2` 24/700, `.h3` 20/600, `.h4` 16/600.
- Текст 16/1.6, `.lead` 18 серым, `.small` 14, `.xs` 12, `.label` 11 капсом .06em.
- Составные слова, которые нельзя рвать, — в `.nw`: «AI-старт», «152-ФЗ», «ИИ-агентами».

## Не делать

- Второй акцентный цвет, градиенты, цветные тени, свечения.
- Подъём и тень при наведении: только подкраска.
- Эмодзи и картинки вместо иконок lucide.
- Тёмную тему: у источника её нет.
- Отзывы и цифры без источника.
